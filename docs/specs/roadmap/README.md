# Roadmap

Filed from the production-readiness review as GitHub issues.

**P1 — AI-native capabilities**

- [#3](https://github.com/Wenrh2004/mdflow/issues/3) Streaming: incremental patch protocol with stable block IDs
- [#4](https://github.com/Wenrh2004/mdflow/issues/4) Streaming: speculative completion of unterminated inline syntax
- [#5](https://github.com/Wenrh2004/mdflow/issues/5) Source positions (byte offsets) on events and tokens
- [#6](https://github.com/Wenrh2004/mdflow/issues/6) CJK-friendly emphasis and soft line breaks
- [#7](https://github.com/Wenrh2004/mdflow/issues/7) Math: `\(…\)` / `\[…\]` delimiters and Pandoc `$` rules
- [#8](https://github.com/Wenrh2004/mdflow/issues/8) GFM completeness: spec suite, table row fix, autolinks, footnotes, alerts
- [#9](https://github.com/Wenrh2004/mdflow/issues/9) LLM profile: reasoning tags, citations and a preset
- [#10](https://github.com/Wenrh2004/mdflow/issues/10) Structured extraction: code blocks, tables, RAG chunker, Markdown and mdast output
- [#11](https://github.com/Wenrh2004/mdflow/issues/11) Renderer: leaf-level overrides and heading anchors

**P2 — maturity**

- [#12](https://github.com/Wenrh2004/mdflow/issues/12) Shrink the public parser API before v1
- [#13](https://github.com/Wenrh2004/mdflow/issues/13) Align remaining APIs with standard-library conventions
- [#14](https://github.com/Wenrh2004/mdflow/issues/14) Release engineering: first tag, changelog, compatibility gates, CI matrix
- [#15](https://github.com/Wenrh2004/mdflow/issues/15) Quality gates: differential fuzzing, OSS-Fuzz, coverage, perf regression
- [#16](https://github.com/Wenrh2004/mdflow/issues/16) Community and documentation
- [#17](https://github.com/Wenrh2004/mdflow/issues/17) Binary size: the one dimension still behind gomark
